# Asif Car Wraps

Premium marketing site for car wrapping, paint protection film, custom wraps, and styling consultations.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npx tsc --noEmit
npm run build
npm run start
```

`npm run build` uses webpack. Turbopack production builds can fail on machines with a small paging file.

## Deploy on Vercel

1. Push this folder to a Git host and import the project in Vercel.
2. Framework preset: Next.js. Build command: `npm run build`.
3. Set `NEXT_PUBLIC_SITE_URL` to the live domain, for example `https://your-domain.com`, so canonical URLs, the sitemap, and structured data use that address.
4. Deploy. No database or email provider is required. The inquiry form opens WhatsApp.
